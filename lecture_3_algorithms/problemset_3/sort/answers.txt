sort1 uses: Bubble sort.

How do you know?: Fastest in going through the sorted files. Since [n + 1] is always bigger than [n], no numbers need to be swapped around, and as such only one pass through the file is needed.

sort2 uses: Merge sort.

How do you know?: Fastest in sorting random and reversed files, and only slightly slower than selecton sort in the already sorted files,
as each of the halved lists is already sorted, it needs to take the sorted file apart and put it back together in the same order without making any changes.

sort3 uses: Selection sort.

How do you know?: On average the middle performing algorithm, except for the sorted files, where it needs to run through each number in the file and compare it to every other number in the file to verify that the list is indeed already sorted.
